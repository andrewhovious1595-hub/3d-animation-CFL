# ClearFault Legal — Court-Admissible 3D Forensic Reconstruction Studio

Static, zero-animation, high-contrast legal engineering website built for instant deployment to **GitHub Pages** (or Cloudflare Pages / Vercel / Netlify).

## Architectural Highlights
- **Strict Zero-Animation Policy:** Global CSS rule enforces `animation: none !important; transition: none !important;` for clinical courtroom precision and instant rendering.
- **No Pricing / Package Clutter:** Focused purely on evidentiary methodology, technical deliverables, and custom forensic case intake.
- **8 Dedicated Practice Verticals (`/niches/*.html`):** Individual SEO-indexed landing pages for Vehicular Crash Reconstruction, Premises Liability & Line-of-Sight, Medical Malpractice DICOM Modeling, Construction Defects, Ballistics & Use-of-Force, Product Liability & IP, Environmental Plumes, and Aviation/Maritime/Rail.
- **10 Adjacent Ecosystem Spinoffs (`/ventures.html`):** Full business architecture for Pro Se Visual Packs, Pre-Suit Demand Kits, Courtroom Hot-Seat Concierge, Interactive WebGL Mediation Rooms, 24/7 Rapid LiDAR Dispatch, Expert Witness Matchmaking, State Bar CLEs, Municipal Liability Twins, Insurance SIU Counter-Fraud Audits, and Post-Verdict Legal PR Licensing.
- **Complete Search Engine Optimization:** Canonical URLs, Open Graph, Twitter Cards, `robots.txt`, `sitemap.xml`, `CNAME`, and embedded Schema.org JSON-LD (`ProfessionalService`, `FAQPage`, `Service`, `TechArticle`).

## GitHub Deployment Steps
1. Create a new GitHub repository (e.g., `clearfault-legal`).
2. Extract this ZIP archive and push all files to the `main` branch.
3. In GitHub, navigate to **Settings → Pages → Build and deployment**, and select **GitHub Actions** as the source.
4. The included `.github/workflows/deploy-pages.yml` workflow will automatically publish the site and bind your custom domain via `CNAME`.
